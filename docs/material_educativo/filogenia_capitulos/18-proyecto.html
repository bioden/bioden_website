Capítulo 18: Proyecto integrador — Filogenia molecular de Hominidae

18.1 Introducción: por qué un pipeline integrador

A lo largo de los 17 capítulos previos hemos aprendido, una a una, las herramientas y conceptos de la filogenia molecular: descarga de secuencias de NCBI, manipulación con BioPython, alineamiento con MAFFT/MUSCLE/Infernal, selección de modelos de sustitución (ADN, proteína, ARN estructural), métodos de distancia, parsimonia, máxima verosimilitud con IQ-TREE y RAxML-NG, inferencia bayesiana con MrBayes, datación con BEAST2, filogenómica con concatenación y species trees, y visualización profesional con ETE3, ggtree e iTOL.

El salto cualitativo entre saber usar cada herramienta y construir un pipeline reproducible y publicable es enorme. La filogenia moderna no es “un árbol” sino un proceso: desde datos crudos hasta cronograma con datación, pasando por alineamiento, modelado, inferencia ML + bayes + datación, validación cruzada y visualización profesional. Cada paso tiene decisiones críticas, parámetros a escoger, y verificaciones de calidad que solo cobran sentido en conjunto.

Este capítulo final integra TODO lo aprendido en un único pipeline profesional que un estudiante podría usar como base de su tesis o un paper. El caso de estudio es la familia Hominidae (grandes monos: humanos, chimpancés, gorilas, orangutanes y gibones), un grupo con abundantes datos moleculares y fósiles, y con preguntas evolutivas profundas (datación de divergencias, relación con homininos).

Important

Objetivo del proyecto: reconstruir la filogenia de Hominidae con datación molecular, usando 5 genes (Cytb, COI, 16S, 18S, RAG1) de 12 especies, con tres métodos complementarios (ML, Bayes, BEAST2) y visualización profesional. El output es un cronograma con tiempos de divergencia y HPD, comparado entre métodos.

5 genes:

  • Cytb (citocromo b, mitocondrial, 1140 bp): evolución rápida, buena para divergencias recientes.
  • COI (citocromo oxidasa subunidad I, mitocondrial, 657 bp): código de barras estándar.
  • 16S rRNA (mitocondrial, ~1450 bp): ARN estructural, evolución moderada.
  • 18S rRNA (nuclear, ~1789 bp): ARN estructural, muy conservado.
  • RAG1 (recombination activating gene 1, nuclear, ~2904 bp): proteína codificante nuclear, evolución lenta.

18.3 Estructura del pipeline

El pipeline consta de 10 pasos organizados en scripts numerados, controlados por un script maestro con configuración externa:

01_descargar.sh           →  obtención de secuencias NCBI
02_limpiar.sh             →  limpieza y renombrado
03_alinear.sh             →  alineamiento por gen
04_modelos.sh             →  selección de modelos
05_concatenar.sh          →  supermatriz + particiones
06_ml.sh                  →  ML particionado (IQ-TREE)
07_bayes.sh               →  Bayesiano (MrBayes)
08_datacion.sh            →  BEAST2 con fósiles
09_postprocesamiento.sh   →  convergencia + comparación
10_visualizar.sh          →  árboles finales + reporte
pipeline_filogenia.sh     →  script maestro
config.conf               →  parámetros configurables

18.4 Script maestro pipeline_filogenia.sh

#!/usr/bin/env bash
# pipeline_filogenia.sh: pipeline integrador de filogenia molecular
# Proyecto: Análisis filogenético completo de Hominidae
# Integra: NCBI → alineamiento → modelos → ML + Bayes + BEAST2 → visualización
set -euo pipefail
IFS=$'\n\t'

# === Cargar configuración ===
CONFIG="${1:-config.conf}"
if [ ! -f "$CONFIG" ]; then
    echo "ERROR: archivo de configuración $CONFIG no encontrado"
    echo "Uso: $0 <config.conf>"
    exit 1
fi
# shellcheck disable=SC1090
source "$CONFIG"

# === Logging con timestamps ===
LOGFILE="${WORKDIR}/pipeline_$(date +%Y%m%d_%H%M%S).log"
mkdir -p "$WORKDIR"
log() {
    echo "[$(date '+Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOGFILE"
}

# === Manejo de errores ===
cleanup() {
    EXIT_CODE=$?
    if [ $EXIT_CODE -ne 0 ]; then
        log "ERROR CRÍTICO: pipeline abortado con código $EXIT_CODE"
        log "Revisa $LOGFILE para detalles."
    else
        log "Pipeline completado exitosamente."
    fi
    # Limpieza de archivos temporales
    rm -f "${WORKDIR}"/tmp_* 2>/dev/null || true
}
trap cleanup EXIT

# === Verificación de dependencias ===
verify_dependencies() {
    log "Verificando dependencias..."
    local required=(efetch seqmagick mafft trimal iqtree2 mb beast treeannotator nw_rename ete3)
    local missing=()
    for cmd in "${required[@]}"; do
        if ! command -v "$cmd" >/dev/null 2>&1; then
            missing+=("$cmd")
        fi
    done
    if [ ${#missing[@]} -gt 0 ]; then
        log "DEPENDENCIAS FALTANTES: ${missing[*]}"
        log "Instalar con: conda install -c bioconda ${missing[*]}"
        exit 1
    fi
    log "Todas las dependencias OK."
}

# === Crear estructura de directorios ===
setup_dirs() {
    log "Creando estructura de directorios..."
    mkdir -p "$DATADIR/raw" "$DATADIR/clean" "$DATADIR/aligned" "$DATADIR/trimmed"
    mkdir -p "$RESULTSDIR/models" "$RESULTSDIR/ml" "$RESULTSDIR/bayes" "$RESULTSDIR/beast" "$RESULTSDIR/trees"
}

# === Pipeline pasos ===
run_step() {
    local step_num="$1"
    local script="$2"
    local description="$3"
    log "=== Paso ${step_num}: ${description} ==="
    local start=$(date +%s)
    if ! bash "$script" "$CONFIG" 2>&1 | tee -a "$LOGFILE"; then
        log "ERROR en paso $step_num"
        exit 1
    fi
    local end=$(date +%s)
    log "Paso $step_num completado en $((end - start)) segundos."
}

# === Pipeline principal ===
main() {
    log "===================="
    log "PIPELINE FILOGENIA HOMINIDAE"
    log "===================="
    log "Workdir: $WORKDIR"
    log "Threads: $THREADS"
    log "Outgroup: $OUTGROUP"
    log "Genes: $GENES"

    verify_dependencies
    setup_dirs

    SCRIPTS_DIR="$(cd "$(dirname "$0")" && pwd)"

    run_step 1  "${SCRIPTS_DIR}/01_descargar.sh"           "Descarga de secuencias NCBI"
    run_step 2  "${SCRIPTS_DIR}/02_limpiar.sh"             "Limpieza y renombrado"
    run_step 3  "${SCRIPTS_DIR}/03_alinear.sh"             "Alineamiento por gen"
    run_step 4  "${SCRIPTS_DIR}/04_modelos.sh"             "Selección de modelos"
    run_step 5  "${SCRIPTS_DIR}/05_concatenar.sh"          "Concatenación y partición"
    run_step 6  "${SCRIPTS_DIR}/06_ml.sh"                  "ML particionado (IQ-TREE)"
    run_step 7  "${SCRIPTS_DIR}/07_bayes.sh"               "Bayesiano (MrBayes)"
    run_step 8  "${SCRIPTS_DIR}/08_datacion.sh"            "Datación BEAST2"
    run_step 9  "${SCRIPTS_DIR}/09_postprocesamiento.sh"   "Post-procesamiento y comparación"
    run_step 10 "${SCRIPTS_DIR}/10_visualizar.sh"          "Visualización y reporte"

    log "===================="
    log "PIPELINE COMPLETADO"
    log "===================="
    log "Resultados en: $RESULTSDIR"
    log "Log completo: $LOGFILE"
    log "Árbol final: $RESULTSDIR/trees/hominidae_final.nwk"
}

main "$@"

18.5 Paso 1: Descarga de secuencias

#!/usr/bin/env bash
# 01_descargar.sh: descarga secuencias desde NCBI
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

log "Descargando secuencias de NCBI..."

# Tabla de accessions por gen y especie
declare -A ACCESSIONS=(
    # Gen_NCBI_accession → nombre_especie
    ["cytb_Homo_sapiens"]="NC_001807"
    ["cytb_Pan_troglodytes"]="NC_001643"
    ["cytb_Pan_paniscus"]="NC_001644"
    ["cytb_Gorilla_gorilla"]="NC_001645"
    ["cytb_Pongo_pygmaeus"]="NC_001646"
    ["cytb_Hylobates_lar"]="NC_002082"
    ["cytb_Macaca_mulatta"]="NC_002769"
    # ... completar para todas las combinaciones
)

# Descargar genomas mitocondriales completos (cytb, coi, 16s incluidos)
for key in "${!ACCESSIONS[@]}"; do
    gene="${key%%_*}"
    species="${key#*_}"
    acc="${ACCESSIONS[$key]}"
    outfile="${DATADIR}/raw/${species}_${gene}.gb"

    if [ -f "$outfile" ]; then
        log "SKIP: $outfile ya existe"
        continue
    fi

    log "Descargando $species / $gene / $acc"
    # Rate limiting: sleep 1s entre requests
    sleep 1
    efetch -db nucleotide -id "$acc" -format gene_bank > "$outfile" 2>/dev/null || {
        log "WARN: no se pudo descargar $acc"
        continue
    }
done

# Para genes nucleares (RAG1, 18S): acceso desde NCBI Nucleotide
# accession list por separado
log "Descarga completada. Total: $(ls "$DATADIR"/raw/ | wc -l) archivos."
Warning

Rate limiting en NCBI: si haces muchas requests sin sleep, NCBI puede bloquear tu IP. Reglas: 1. Máximo 3 requests por segundo (sleep 0.34s). 2. Identificarse con email: añade -email tu@correo.com si usas Biopython’s Entrez. 3. Para descargas masivas: usar datasets CLI de NCBI (más eficiente que efetch).

18.6 Paso 2: Limpieza

#!/usr/bin/env bash
# 02_limpiar.sh: limpieza de secuencias y renombrado
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

log "Limpiando secuencias..."

mkdir -p "$DATADIR/clean"

# Convertir multi-línea a una línea por secuencia, renombrar IDs
python3 <<EOF
import os
import glob
from Bio import SeqIO

raw_dir = "${DATADIR}/raw"
clean_dir = "${DATADIR}/clean"

for gb_file in glob.glob(os.path.join(raw_dir, "*.gb")):
    # Extraer gene features (CDS, rRNA) del GenBank
    base = os.path.basename(gb_file).replace('.gb', '')
    for rec in SeqIO.parse(gb_file, "genbank"):
        for feature in rec.features:
            if feature.type in ("CDS", "rRNA", "tRNA"):
                gene_name = feature.qualifiers.get('gene', ['unknown'])[0].lower()
                if gene_name not in ["cytb", "coi", "co1", "16s", "18s", "rag1"]:
                    continue
                # Normalizar nombres de genes
                if gene_name == "co1": gene_name = "coi"
                gene_seq = feature.extract(rec.seq)
                species = base.replace('_', ' ')
                seq_id = base.replace(' ', '_') + '_' + gene_name
                # Guardar como FASTA
                out_file = os.path.join(clean_dir, f"{seq_id}.fasta")
                with open(out_file, "w") as f:
                    f.write(f">{seq_id}\n{str(gene_seq).upper()}\n")
                print(f"  {seq_id}: {len(gene_seq)} bp")

print("\nLimpieza completada.")
EOF

# Estadísticas
log "Estadísticas post-limpieza:"
echo "Total secuencias: $(find "$DATADIR"/clean -name '*.fasta' | wc -l)"
echo "Por gene:"
for gene in $GENES; do
    n=$(find "$DATADIR"/clean -name "*_${gene}.fasta" | wc -l)
    echo "  $gene: $n secuencias"
done

18.7 Paso 3: Alineamiento

#!/usr/bin/env bash
# 03_alinear.sh: alineamiento por gen
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

mkdir -p "$DATADIR/aligned" "$DATADIR/trimmed"

log "Alineando genes..."

for gene in $GENES; do
    log "=== Gene: $gene ==="

    # Concatenar todas las secuencias del gen en un solo archivo
    input_file="${DATADIR}/aligned/${gene}_raw.fasta"
    cat "${DATADIR}/clean"/*_${gene}.fasta > "$input_file"

    # Elegir algoritmo según tipo de gen
    case $gene in
        16s|18s)
            # ARN estructural: MAFFT G-INS-i (alternativa a Infernal)
            log "  Alineando $gene con MAFFT G-INS-i (ARN estructural)"
            mafft --genafpair --maxiterate 1000 "$input_file" > "${DATADIR}/aligned/${gene}_aln.fasta" 2>/dev/null
            ;;
        rag1)
            # Proteína: alinear proteína primero, retrotraducir
            log "  Alineando $gene (proteína-first con pal2nal)"
            # Transcribir a proteína
            python3 -c "
from Bio import SeqIO
from Bio.Seq import Seq
import sys
for rec in SeqIO.parse('${input_file}', 'fasta'):
    prot = rec.translate(cds=False, to_stop=True)
    print(f'>{rec.id}')
    print(str(prot.seq))
" > "${DATADIR}/aligned/${gene}_prot.fasta"
            # Alinear proteína con MUSCLE
            muscle5 -super5 "${DATADIR}/aligned/${gene}_prot.fasta" -output "${DATADIR}/aligned/${gene}_prot_aln.fasta" 2>/dev/null
            # Retrotraducir a codones con pal2nal
            pal2nal.pl "${DATADIR}/aligned/${gene}_prot_aln.fasta" "$input_file" -output fasta -nomismatches > "${DATADIR}/aligned/${gene}_aln.fasta"
            ;;
        cytb|coi)
            # ADN codificante: MAFFT auto
            log "  Alineando $gene con MAFFT"
            mafft --auto "$input_file" > "${DATADIR}/aligned/${gene}_aln.fasta" 2>/dev/null
            ;;
    esac

    # Recortar con trimAl
    log "  Recortando $gene con trimAl"
    trimal -in "${DATADIR}/aligned/${gene}_aln.fasta" \
           -out "${DATADIR}/trimmed/${gene}_trim.fasta" \
           -automated1 2>/dev/null

    # Estadísticas
    n_seqs=$(grep -c '>' "${DATADIR}/trimmed/${gene}_trim.fasta")
    length=$(seqmagick info "${DATADIR}/trimmed/${gene}_trim.fasta" | awk '/length/{print $3}' | head -1)
    log "  $gene: ${n_seqs} secuencias, ${length} bp tras recorte"
done

log "Alineamiento completado."

    ["coi"]="GTR,HKY,TIM,TVM"
    ["16s"]="GTR,RNA16A,RNA16B,RNA16D"
    ["18s"]="GTR,RNA16A,RNA16B,RNA16D"

for gene in $GENES; do

    iqtree2 -s "${DATADIR}/trimmed/${gene}_trim.fasta" \
            -m MFP -mset "${MSET[$gene]}" \
            -pre "${RESULTSDIR}/models/${gene}" \
            -T "$THREADS" 2>&1 | grep -E "(Best-fit|LogL|AIC)" || true
done

# Resumen de modelos
log "=== Resumen de modelos por gen ==="
{
    echo "Gene,BestModel,LogL,AIC"

        logl=$(grep "Log-likelihood" "${RESULTSDIR}/models/${gene}.iqtree" | awk '{print $NF}')
        aic=$(grep -m1 "AIC" "${RESULTSDIR}/models/${gene}.iqtree" | awk '{print $NF}')
        echo "${gene},${model},${logl},${aic}"
    done
} | column -t -s,

18.9 Paso 5: Concatenación y partición

#!/usr/bin/env bash
# 05_concatenar.sh: concatenar alineamientos y crear archivo de partición
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

log "Concatenando genes en supermatriz..."

# Usar AMAS para concatenar
ALIGNMENTS=""
for gene in $GENES; do
    ALIGNMENTS+="${DATADIR}/trimmed/${gene}_trim.fasta "
done

AMAS.py concat -f fasta -d dna \
    -i $ALIGNMENTS \
    -o "${DATADIR}/concatenated.fasta" \
    -p "${DATADIR}/partitions.txt"

# Añadir modelos óptimos a las particiones (formato IQ-TREE)
log "Añadiendo modelos óptimos a particiones..."
{
    while IFS='= ' read -r _ gene _ positions; do
        gene_clean=$(echo "$gene" | tr -d ' ,')
        positions_clean=$(echo "$positions" | tr -d ' \n')
        model=$(grep -m1 "Best-fit model" "${RESULTSDIR}/models/${gene_clean}.iqtree" | awk -F: '{print $2}' | tr -d ' ')
        echo "${model}, ${gene_clean} = ${positions_clean}"
    done < <(cat "${DATADIR}/partitions.txt")
} > "${DATADIR}/partitions_models.txt"

# Estadísticas de la supermatriz
python3 <<EOF
from Bio import AlignIO
from collections import Counter

aln = AlignIO.read("${DATADIR}/concatenated.fasta", "fasta")
n_taxa = len(aln)
n_sites = aln.get_alignment_length()

informative = 0
for i in range(n_sites):
    col = str(aln[:, i]).upper()
    cnt = Counter(c for c in col if c not in '-?N')
    if sum(1 for c, n in cnt.items() if n >= 2) >= 2:
        informative += 1

print(f"\n=== ESTADÍSTICAS SUPERMATRIZ ===")
print(f"Taxones:              {n_taxa}")
print(f"Sites totales:        {n_sites}")
print(f"Sitios informativos:  {informative} ({informative/n_sites*100:.1f}%)")
print(f"Particiones:          $(grep -c '=' ${DATADIR}/partitions.txt)")
EOF

log "Concatenación completada: ${DATADIR}/concatenated.fasta"
log "Particiones: ${DATADIR}/partitions_models.txt"

#!/usr/bin/env bash

18.11 Paso 7: Bayesiano con MrBayes

#!/usr/bin/env bash
# 07_bayes.sh: análisis bayesiano con MrBayes
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

mkdir -p "$RESULTSDIR/bayes"

log "Preparando NEXUS para MrBayes..."

# Convertir a NEXUS
seqmagick convert --format nexus "${DATADIR}/concatenated.fasta" "${RESULTSDIR}/bayes/hominidae.nex"

# Añadir bloque MrBayes con particiones
cat >> "${RESULTSDIR}/bayes/hominidae.nex" <<'EOF'

BEGIN MRBAYES;
    charset cytb  = 1-1140;
    charset coi   = 1141-1797;
    charset 16s   = 1798-3247;
    charset 18s   = 3248-5036;
    charset rag1  = 5037-7940;
    partition by_gene = 5: cytb, coi, 16s, 18s, rag1;
    set partition = by_gene;
    lset applyto=(all) nst=6 rates=invgamma;
    unlink statefreq=(all) revmat=(all) shape=(all) pinvar=(all);
    set autoclose=yes nowarn=yes;
    mcmc ngen=5000000 samplefreq=1000 printfreq=1000 nchains=4 nruns=2 savebrlens=yes;
    sumt burnin=1250;
    sump burnin=1250;
END;
EOF

# NOTA: las posiciones deben corresponder a partitions.txt generado en paso 5

log "Ejecutando MrBayes..."
cd "${RESULTSDIR}/bayes"
mb -i hominidae.nex > mb.log 2>&1
cd -

# Verificar convergencia
ASDSF=$(grep "Average standard deviation" "${RESULTSDIR}/bayes/mb.log" | tail -1 | awk '{print $NF}')
log "ASDSF final: $ASDSF"

# Verificar ESS con coda (R)
Rscript -e '
library(coda)
post <- read.table("'"${RESULTSDIR}"'/bayes/hominidae.nex.p", header=TRUE, sep="\t", skip=1)
ess <- effectiveSize(post)
cat("ESS mínimo:", round(min(ess), 1), "\n")
cat("Parámetros con ESS < 200:", sum(ess < 200), "\n")
' 2>/dev/null || true

# Convertir consenso a Newick
python3 -c "

18.15 Análisis de resultados

Tras ejecutar el pipeline completo, analizar:

1. CONGRUENCIA TOPOLOGICA:
   - ML, Bayes y BEAST2 ¿coinciden en clados principales?
   - RF distance entre topologías (idealmente < 10)

2. SOPORTE:
   - Bootstrap ML ≥ 95 para clados principales
   - Posterior prob Bayes ≥ 0.95
   - Nodos problemáticos (soporte bajo) → identificar y discutir

3. DATACIÓN:
   - Edades estimadas vs calibraciones (¿coinciden?)
   - HPD 95% estrechos para nodos bien soportados
   - Comparar con literatura (Steiper & Young 2009)

4. ESS y CONVERGENCIA:
   - ESS ≥ 200 en todos los parámetros BEAST2
   - ASDSF < 0.01 en MrBayes
   - Si no se cumple, relanzar con más generaciones

Ejemplo de resultados esperados:

=== Distancias RF ===
ML vs Bayes:    0 (topologías idénticas)
ML vs BEAST:    0 (topologías idénticas)
Bayes vs BEAST: 0

Tip

Interpretación biológica: - Topologías congruentes → la filogenia es robusta a método de inferencia. - Edades dentro de rangos fósiles → las calibraciones son coherentes. - Homo–Pan ~6.4 Myr consistente con fósiles como Sahelanthropus (7 Myr) y Orrorin (6 Myr). - Pongo split ~18 Myr coincide con Sivapithecus (12.5 Myr, mínimo).

#!/usr/bin/env bash
# pipeline_paralelo.sh: versión paralela del pipeline
set -euo pipefail
source "$1"

log() { echo "[$(date '+%H:%M:%S')] $*"; }

# === Medir tiempo secuencial ===
log "=== Versión SECUENCIAL ==="
START_SEQ=$(date +%s)

for gene in $GENES; do
    log "Procesando $gene (secuencial)..."
    mafft --auto "${DATADIR}/clean/${gene}.fasta" > "${DATADIR}/aligned/${gene}_aln.fasta" 2>/dev/null
    trimal -in "${DATADIR}/aligned/${gene}_aln.fasta" -out "${DATADIR}/trimmed/${gene}_trim.fasta" -automated1
    iqtree2 -s "${DATADIR}/trimmed/${gene}_trim.fasta" -m MFP -T 1 -pre "${RESULTSDIR}/models/${gene}" 2>/dev/null
done

END_SEQ=$(date +%s)
TIME_SEQ=$((END_SEQ - START_SEQ))
log "Tiempo secuencial: ${TIME_SEQ}s"

# === Versión paralela ===
log "=== Versión PARALELA ==="
START_PAR=$(date +%s)

PIDS=()
for gene in $GENES; do
    (
        log "Procesando $gene (paralelo)..."
        mafft --auto "${DATADIR}/clean/${gene}.fasta" > "${DATADIR}/aligned/${gene}_aln.fasta" 2>/dev/null
        trimal -in "${DATADIR}/aligned/${gene}_aln.fasta" -out "${DATADIR}/trimmed/${gene}_trim.fasta" -automated1
        iqtree2 -s "${DATADIR}/trimmed/${gene}_trim.fasta" -m MFP -T 1 -pre "${RESULTSDIR}/models/${gene}" 2>/dev/null
    ) &
    PIDS+=($!)
done

# Esperar a que todos terminen
for pid in "${PIDS[@]}"; do
    wait "$pid" || {
        log "ERROR: proceso $pid falló"
        exit 1
    }
done

END_PAR=$(date +%s)
TIME_PAR=$((END_PAR - START_PAR))
log "Tiempo paralelo: ${TIME_PAR}s"

# === Reporte ===
log "=== COMPARACIÓN DE TIEMPOS ==="
echo "Secuencial: ${TIME_SEQ}s"
echo "Paralelo:   ${TIME_PAR}s"
echo "Speedup:    $(echo "scale=2; ${TIME_SEQ}/${TIME_PAR}" | bc)x"

Important

Buenas prácticas aplicadas en el pipeline (todas las aprendidas en el curso): - set -euo pipefail: aborta ante errores. - Shebang #!/usr/bin/env bash: portable. - Logging con timestamps en cada paso. - Validación de argumentos y dependencias. - Funciones modulares con local. - Exit codes significativos. - trap para limpieza en salida/error. - Configuración externa (config.conf) para reproducibilidad. - Verificación de ESS/ASDSF antes de aceptar resultados. - Comparación cruzada de métodos (ML/Bayes/BEAST2).

Tip

Cierre del curso: Este pipeline es la integración de 17 capítulos de aprendizaje. Cada paso (descarga, alineamiento, modelos, ML, bayes, datación, visualización) merecería su propio curso, pero juntos forman un proceso profesional que puedes usar en investigación real. Las próximas ampliaciones serían: - Filogenómica con genoma completo (1000+ genes). - Análisis de selección (PAML, dN/dS). - Filogeografía (estructuración poblacional, BEAST2 con tips datados). - Redes filogenéticas (PhyloNetworks para hibridación). - Análisis de biogeografía (BioGeoBEARS).
